# Практическая работа № 8 - Взаимоблокировки (Вариант B)

## 1. Выполненные задания
1. **Алгоритм банкира (`banker.py`)**: реализована полная проверка безопасных состояний на наборах `bank1.txt` и `bank2.txt`, а также обработка запросов с откатом.
2. **Детектор тупиков (`tracked_lock.py`)**: написана обертка `TrackedLock`, которая строит граф ожидания и при помощи алгоритма DFS выявляет циклы в реальном времени, предотвращая зависание потоков.
3. **Обедающие философы (`philosophers.py`)**: реализовано безопасное решение проблемы тупиков путем упорядочивания захвата ресурсов (вилок).

## 2. Контрольные вопросы
1. **Почему упорядочивание захвата ресурсов исключает deadlock?**
   - Оно нарушает одно из четырех необходимых условий возникновения тупика по Коффману — условие «кругового ожидания» (circular wait), так как все потоки запрашивают ресурсы в строго глобальном порядке.
2. **Почему алгоритм банкира редко применяется в универсальных ОС?**
   - В реальных системах заранее неизвестно максимальное количество ресурсов, которое может потребоваться каждому процессу в течение его жизненного цикла, а также динамически меняется число активных процессов.
