# Практическая работа №5. Планирование процессов CPU

## Цель работы

Разработать симулятор планирования процессов CPU, реализовать несколько алгоритмов планирования и сравнить их эффективность по времени ожидания, времени оборота, времени отклика и количеству переключений между процессами.

## Используемые технологии

- Python 3
- Ubuntu 24.04 (WSL)
- Matplotlib
- Git и GitHub

## Реализованные алгоритмы

1. **FCFS (First Come, First Served)** — первым выполняется процесс, который раньше пришёл.
2. **SJF (Shortest Job First)** — выбирается процесс с наименьшим временем выполнения.
3. **SRTF (Shortest Remaining Time First)** — выполняется процесс с наименьшим оставшимся временем.
4. **Priority Scheduling** — планирование по приоритету с возможностью вытеснения.
5. **Round Robin (RR)** — каждому процессу выделяется ограниченный квант времени.

Дополнительно реализовано старение приоритетов (aging), которое повышает приоритет ожидающих процессов.

## Формат входных данных

Каждая строка файла содержит четыре значения:

```text
PID arrival_time burst_time priority
```

- `PID` — идентификатор процесса.
- `arrival_time` — время поступления процесса.
- `burst_time` — необходимое процессу время CPU.
- `priority` — приоритет процесса.

В `set1.txt` находятся 4 процесса для проверки алгоритмов. `set2.txt` содержит 20 процессов для сравнения производительности алгоритмов, а `set3.txt` предназначен для эксперимента с одним длинным и несколькими короткими процессами.

## Запуск программы

### Генерация наборов данных

```bash
python3 make_sets.py
python3 make_starvation.py
```

### Проверка алгоритмов на set1.txt

```bash
python3 sched.py --algo fcfs set1.txt
python3 sched.py --algo sjf set1.txt
python3 sched.py --algo srtf set1.txt
python3 sched.py --algo priority set1.txt
python3 sched.py --algo rr --quantum 3 set1.txt
```

### Сравнение алгоритмов на set2.txt

```bash
python3 sched.py --algo fcfs set2.txt
python3 sched.py --algo sjf set2.txt
python3 sched.py --algo srtf set2.txt
python3 sched.py --algo priority set2.txt
python3 sched.py --algo rr --quantum 3 set2.txt
```

### Построение графика Round Robin

Для построения графика необходимо установить Matplotlib:

```bash
python3 -m pip install matplotlib
python3 plot_rr.py
```

График сохраняется в файле `rr_graph.png`.

### Проверка старения приоритетов

Без старения:

```bash
python3 sched.py --algo priority starvation.txt
```

Со старением:

```bash
python3 sched.py --algo priority --aging --aging-interval 5 starvation.txt
```

## Результаты эксперимента на set1.txt

| Алгоритм | Среднее ожидание | Средний оборот |
|---|---:|---:|
| FCFS | 8.75 | 15.25 |
| SRTF | 6.50 | 13.00 |
| Round Robin (q = 3) | 13.50 | 20.00 |

На данном наборе данных SRTF показал наименьшее среднее время ожидания и оборота. Round Robin обеспечивает более равномерное распределение процессорного времени, но увеличивает среднее ожидание.

## Результаты на set2.txt

| Алгоритм | Среднее ожидание | Средний оборот |
|---|---:|---:|
| FCFS | 252.45 | 281.35 |
| SJF | 204.60 | 233.50 |
| SRTF | 204.60 | 233.50 |
| Priority | 257.10 | 286.00 |
| Round Robin (q = 3) | 413.85 | 442.75 |

В этом эксперименте SJF и SRTF получили одинаковые результаты, поскольку процессы поступают последовательно и новый процесс не вытесняет уже выполняющийся процесс с более коротким оставшимся временем.

Round Robin с квантом 3 показал большее среднее время ожидания, поскольку процессы многократно возвращаются в очередь.

| Квант | Среднее ожидание | Переключения |

С увеличением кванта количество переключений уменьшается. Однако среднее время ожидания не обязательно уменьшается монотонно. Выбор кванта представляет собой компромисс между отзывчивостью системы и количеством переключений.

## Эксперимент со старением приоритетов

Без aging среднее ожидание составило 60.97, а среднее время отклика — 56.13.

С aging при интервале 5 среднее ожидание составило 62.13, а среднее время отклика — 54.97.

В данном эксперименте старение немного улучшило среднее время отклика, но увеличило среднее ожидание. Это показывает, что aging не обязательно улучшает все метрики одновременно. Его основная задача — уменьшить риск длительного ожидания процессов с низким приоритетом.

## Вывод

В ходе практической работы был разработан симулятор планирования процессов CPU и реализованы алгоритмы FCFS, SJF, SRTF, Priority и Round Robin.

Были рассчитаны среднее время ожидания, время оборота, время отклика и загрузка CPU. Также выполнено сравнение различных квантов Round Robin и проверено влияние старения приоритетов.

Эксперименты показали, что выбор алгоритма зависит от характеристик процессов и целей системы. SJF и SRTF могут уменьшать среднее ожидание, Round Robin обеспечивает распределение процессорного времени между процессами, а aging помогает бороться с длительным ожиданием при приоритетном планировании.
