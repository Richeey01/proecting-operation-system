
# Практическая работа № 3
## Процессы в Linux

### Цель работы
Изучить процессы и их состояния в Linux, научиться создавать
дочерние процессы, ожидать их завершения и исследовать память.

### Среда выполнения
- ОС: Ubuntu 24.04 в WSL
- Язык программирования: Python 3
- Информация о процессах: /proc

Файл: ptree.py

процессы текущего пользователя и строит дерево по PID и PPID.
Для каждого процесса выводятся PID, состояние, RSS и имя.

### Задание 2. Создание дочерних процессов
Файл: runner.py

Родитель создаёт N дочерних процессов через fork().

Родитель ждёт завершения детей через waitpid() и выводит
код возврата и время выполнения.

### Задание 3. Зомби и сирота
Файлы: zombie.py, orphan.py

Зомби — завершившийся дочерний процесс, статус которого
ещё не забрал родитель. После waitpid() запись о зомби
удаляется из таблицы процессов.

Сирота — процесс, родитель которого завершился раньше него.
Linux переподчиняет такой процесс другому процессу.

### Вывод
В ходе работы изучены дерево процессов, создание и ожидание
дочерних процессов, состояния зомби и сироты, а также механизм
